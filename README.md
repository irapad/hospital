## 📱 Applications

### 🧮 Calculator App
A beautiful, responsive calculator with full keyboard support

**✨ Features:**
- ➕ Basic arithmetic operations (+, −, ×, ÷)
- ⌨️ Full keyboard support (numbers, operators, Enter, Esc, Backspace)
- 🎨 Modern gradient UI design
- 📱 Fully responsive - works on all devices
- 🌐 Works offline - single HTML file
- 🇹🇭 Thai language support

**🔗 [Open Calculator](https://cdn.jsdelivr.net/gh/irapad/hospital@main/calculator.html)**

## 🚀 Quick Deploy

This project includes a quick deployment script:

```bash
./deploy.sh "your commit message"
```

The script will automatically:
- Add all changes
- Commit with your message
- Push to GitHub
- Show the live URL

## 💡 Usage

All applications are self-contained single HTML files. Simply:

1. **Download** the HTML file you want
2. **Open** it in any modern web browser
3. **Use** immediately - no installation required!

Or access them directly via CDN:
```
https://cdn.jsdelivr.net/gh/irapad/hospital@main/[filename].html
```
